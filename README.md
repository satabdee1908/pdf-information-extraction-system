# Intelligent PDF Information Extraction System

## Overview

The Intelligent PDF Information Extraction System is an AI-powered document processing application that extracts meaningful information from PDFs and images. The system combines OCR, Machine Learning, Natural Language Processing, and Large Language Models to classify documents, extract important entities, generate summaries, and provide structured outputs.

## Features

* PDF and Image Upload Support
* OCR-Based Text Extraction
* Machine Learning Document Classification
* Named Entity Recognition (NER)
* AI Generated Summaries and Key Points
* Structured Information Extraction
* JSON-Based Response Generation
* FastAPI Backend API
* Simple Web-Based User Interface

## Project Outcome

The system successfully performs document classification, OCR-based text extraction, named entity recognition, and AI-powered information extraction from PDFs and images.

The project integrates Machine Learning, Natural Language Processing, OCR, and Large Language Models into a unified document understanding pipeline capable of processing both structured and unstructured documents.
